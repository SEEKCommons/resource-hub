# Instruction Examples

- **Task:** “Add a colleague’s software to the hub.”
  - **Exemplar answer:** “Register in Zenodo (or repository DOI), link it to your ORCID, then reconcile to a Wikidata item; we’ll ingest the DOI + Q‑ID link on the next sync. Here’s the step‑by‑step…”
- **Task:** “Explain why this claim is true.”
  - **Exemplar answer:** “Path: `Person(Qxxx) → author of → Work(Qyyy) → presented at → Venue(Qzzz)`; see items and references below. Inference: `worksFor` implies Person/Organization types (RDFS domain/range).”
